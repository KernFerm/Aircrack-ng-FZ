# Aircrack-ng FZ v1.0.8

Aircrack-ng FZ provides real offline `.cap`, `.pcap`, `.pcapng`, and IVS2 inspection on Flipper Zero, live stock-device Sub-GHz/NFC/LF RFID measurements, and an optional UART controller for genuine Aircrack-ng on a Raspberry Pi or other Linux computer with compatible Wi-Fi hardware.

This maintenance release refreshes all application/companion version metadata and is clean-built and validated for Flipper target f7/API 87.1.

Download the attached `aircrack_ng_fz.fap`, connect the Flipper, and copy it to `/ext/apps/Tools/`. External Wi-Fi operation still requires the documented Linux host and monitor-mode adapter; the stock Flipper does not contain Wi-Fi hardware.
